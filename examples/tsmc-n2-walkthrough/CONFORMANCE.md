# N2 首例對照方法檔

對照對象：方法檔 `product-technology-method.md`（`product-technology-v1`）與本資料夾的 N2 互動頁（v1.0，2026-11-07 對齊後）。

判準：做法有差異時，先檢討方法檔是否規定得太細；方法檔的規定有道理，才改報告。每一項寫「修方法」或「修報告」，
狀態分「已改」與「待決」。「待決」的項目要等獨立審查或維護者裁決。

## 對齊時已改的資料格式

這些是把 N2 互動頁搬到骨架格式時的機械改動，不算不符項：

- 加 `META` 常數。值取自 N2 原本產 md 的腳本：front matter、KPI、閱讀說明、幕導語；頁首與頁尾的文字取自原本寫死的 HTML。
- `TAG` 改成 `{ name, level }`，key `tsmc` 改名 `official`，`SRC` 裡的 `t` 一起改。
- `ACTS` 每一幕加 `line: 'both'`：N2 的製程步驟本身就是供應鏈（方法檔 2.2）。
- `STEPS` 拿掉 `ready`。第二幕（步驟 6–12）原本靠引擎補剖面標題，改成每一步明寫 `pa`、`pb`。
- 材料色票從引擎的 `swatch()` 搬成 `SWATCH` 常數。
- 場景搬進 `buildScene()`。三張官方圖的 `photo()` 補上來源網址，載入失敗時改顯示卡片。
- 引擎、版面與 CSS 換成骨架版本；N2 自己的介面字樣（「製程步驟」「製程動畫」「這一步相關的設備與材料廠商」）保留。

重產 md 和對齊前的 md 相比，差在三處，都是產檔腳本的寫法改了，頁面內容沒有變：

- front matter 的值一律加引號，並多一行 `methodology_version`。
- 廠商表的欄名「製程類別」改成「類別」，說明句的「依製程類別列出」改成「依類別列出」（17 步各一次）。
- 截圖有少量反鋸齒差異，肉眼看不出；同一版頁面重跑兩次，截圖逐位元相同。
