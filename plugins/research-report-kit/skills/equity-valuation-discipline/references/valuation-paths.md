# 三條估值路徑（完整方法）

路徑判別見 SKILL.md。歸類結果必須寫進報告的估值節開頭。

---

## 路徑 A｜SOTP（多分部且各有獨立獲利揭露）

### A.1 基本方法

- 完整拆解**所有**事業分部，使用最新財報與法說會數據。
- 對**實際有在成長**的業務給高倍數；對衰退／持平業務僅以帳面淨值或低倍數計算。
- 估值以**三種形式並陳**：目標股價（三情境）、分部 EV 與合理市值區間、同業 forward P/E 比較表。
- 每個假設都要有一手來源佐證。

### A.2 倍數上限的出身與適用邊界

::: note
成長分部常見的「30x 上限」這類數字**都是從某個特定母體校準出來的**，不是普世常數。規則：**不當硬上限，當「須說明母體」的預設值**——成長分部的倍數應由

```
justified P/E = (1 − g/ROIC) × (1 + g) / (WACC − g)
```

推得並揭露所用的 ROIC、g、WACC；直接指定倍數者須在 Caveats 寫明沿用哪個母體的預設值。

此規則適用路徑 A 與 B，**不適用路徑 C**（後者用衍生倍數）。
:::

### A.3 控股／流動性折價

- 各分部加總後套用 **0–15%** 折價；**>15% 須有具體理由**（治理紅旗、關係人交易、分部無獨立上市參照且流動性差）。
- **來源**：Berger & Ofek（1995, JFE）多角化折價平均 13–15%；Campa & Kedia（2002）指出其中一部分為自我選擇效果。
- ⚠️ 「折價取上緣」＋「衰退分部只給帳面淨值」構成**重複懲罰**——兩者只能收一次。
- 未套折價的 SOTP 數字只能當「理論上限」呈現。
- **適用範圍限定**：折價只適用多分部／控股結構；路徑 B、C 無適用對象，**不得硬套**。

---

## 路徑 B｜單一事業週期股（常態化獲利力 × 週期位階倍數）

### B.1 主軸：獲利正常化雙法

爬坡期、停機、一次性費用等「當期獲利失真」的分部，正常化獲利須**雙法並列、取其區間**：

- **(a) 正常化年化法**：取最近一個未失真季度 ×4。
- **(b) 遠期目標折現法**：以公司揭露的中期目標獲利折現回估值基年。
- 兩法差距即該分部的**執行風險價差**，須在 Caveats 揭露。

::: caveat
**峰值年化警告**：(a) 法的「保守」性質**取決於所取季度的週期位置**。若最近未失真季度恰為週期峰值，(a) 法是**最進取的錨**，不是保守錨。

三步處理：①判斷該季度在週期中的位置並明寫；②位於高檔時標註為「峰值年化（進取錨）」，保守錨改用跨週期常態化獲利；③「峰值 EPS × 低倍數看起來便宜」須在 Caveats 明寫。
:::

### B.2 三情境與出場倍數

1. 建立常態化營收與毛利率假設，出**保守／基準／樂觀三情境**。**合約保底型收入與現貨曝險部分分開列示**，差額即週期曝險規模。
2. **多年橋接模型（選用）**：公司將產生鉅額現金流並執行買回時可建 2–3 年橋接；橋接假設**全數屬本報告自設**，須列入 Caveats 的「無外部來源」清單。
3. **出場倍數**：採該產業週期股慣用區間（例：記憶體 6–12x 常態化 EPS），高檔取下緣、低檔取上緣，**並列跨週期 P/B 或 EV／重置成本作為對照**（週期底部 EPS 常為負，倍數失效）。此為框架紀律值而非市場觀察值，須明寫。
4. **交叉驗證**：Reverse DCF（本路徑**仍計為獨立一方**）＋資產法必做。
5. **控股折價不適用。**
6. 若需呈現「市場動能定價」，另列為「市場情境／寬鬆錨」，**不得混入目標價序列**。
7. 三情境經情境機率加權得紀律值（SKILL.md 第二步）。

## 路徑 C｜單一事業成長股（遠期目標折現 ＋ 衍生出場倍數）

### C.1 主軸＝遠期目標折現法

以**營收錨（C.2）× 成熟期獲利力**建立出場年價值基礎，套用**衍生出場倍數（C.4）**，折現回估值基年。

- 三情境的分歧建在**利潤率、fade 假設與情境機率**，而非營收（營收由錨級決定）。
- ⚠️ **基準情境參數紀律**：基準情境的每一個參數（利潤率、終端利潤率、`g₁`、`N`、`k`）**取無偏最佳估計（該取中值就取中值）**，不得因「保守」而取下緣。財務品質警示改由**情境機率**承接（提高熊情境機率，或新增「失效情境」）。
- **B.1(a) 正常化年化法在本路徑不適用。**

### C.2 營收錨階序

依可信度分五級，**一律取最高可用級別**，並在估值節開頭聲明實際採用級別：

| 級別 | 錨 | 資料層級 | 適用條件 |
|---|---|---|---|
| **L0** | 公司揭露之中期營收目標，**且同時揭露長期營運模型之營業利益率或淨利率** | l1 | 有此級即**必須**使用 |
| **L0.5** | **半量化中期目標**：有明確量化下限或倍數關係，但無上限／無區間、或僅涵蓋單一年度、或只給毛利率目標 | l1（弱端） | 須滿足三個使用條件 |
| **L1** | 賣方共識全樣本 | l2 | 目標年覆蓋家數 **≥5**；須揭露家數與離散度 |
| **L2** | 共識（覆蓋 2–4 家，或已見公司自陳的減速訊號） | l2（降級） | 折讓理由須逐項列出 |
| **L3** | 純自建營收路徑 | 自設假設 | 最後手段；須在 **TL;DR** 揭露 |

**L0 與 L0.5 的分界（三條同時成立才算 L0）**：①涵蓋期間 ≥2 個完整年度；②有區間或中值；③揭露 long-term **operating** model 的營業利益率或淨利率——**只給毛利率目標不算**。

**L0.5 的三個使用條件（缺一不可）**：①強制交叉佐證，並列該目標年最高可用共識級別，背離 >20% 降級 L1；②僅作下限使用；③敘述性措辭逐字引用公司原文並註明出處與日期。

::: note
**錨級須對準「出場年」而非「最近年度」**：錨級判定的對象是**出場年的營收**。近年指引對出場年沒有錨定力者，錨級仍為 L1。判定時須明寫「本錨級是針對出場年 20XX 判定的」。
:::

#### 折讓 ＝ 基礎折讓 ＋ 信用調整

| 錨級 | 基礎折讓 |
|---|---|
| L0 | 0% |
| L0.5 | 5% |
| L1 | 10% |
| L2 | 20% |
| L3 | 30% |

**信用調整**：走 L0／L0.5 者，須查經營層信用檢核表（歷年法說會／投資人日承諾 vs 實際達成率）——**近三次中期承諾達成率 <70%，或有「重大事實未於法說會揭露」的警示者，自動降一級處理**（L0 → L0.5，L0.5 → L1）。理由：零折讓隱含「公司比賣方準」，若同時設了達成率表卻不接回錨級，等於白做。

::: caveat
**折讓數列的母體聲明**：5／10／20／30% 為等距經驗值，尚無歷史預測誤差校準。**待辦**：以自己累積的「出場年營收共識 vs 實際」誤差、或公開的 2–3 年期營收預測誤差中位數重設；覆蓋家數 <5 的折讓以該子樣本誤差設定。
:::

⛔ **這是錨級的唯一懲罰。出場倍數與 WACC 均不受錨級影響。**

**利潤率橋接的逐項揭露**：走 L0.5／L2／L3 時，利潤率須以**橋接表**逐項列出，每一項的幅度都算「本報告自設假設」。

### C.3 Reverse DCF：分歧定位（強制，但不計為獨立驗證一方）

與主軸共用同一 fade 引擎。用途是把分歧鎖定到具體參數：

- 輸出矩陣：**終端 FCF 利潤率 × WACC → 現價隱含的 `g₁` 與終端年營收**。
- 「現價隱含 `g₁`」與「現價隱含倍數」均須揭露。
- 必附「隱含終端年營收 ÷ 公司自訂 TAM ＝ 隱含市占」，並**並列「vs 該市場現任第一名份額」與「vs 本公司現況份額之倍數」**（比固定的「>10% 須論證」門檻更有訊息量）。

### C.4 出場倍數＝衍生值，不是決定值

**出場倍數不得直接指定，一律由 fade 模型推導。預設形狀為成長連動式**，線性插值只作對照欄。

```python
def justified_multiple(g1, N, g_term, nopat_margin_path, k, wacc):
    """
    成長連動 fade：capex 強度的驅動是成長率，不是時間。
    g1                : 出場年後第一年的營收成長率
    N                 : fade 年數（預設 5；成長自 g1 線性衰減至 g_term）
    g_term            : 終端成長率（≤3% 或估值幣別長期名目 GDP，取低者；
                        若隱含終端 RONIC < WACC，改取 0%）
    nopat_margin_path : 長度 N 的 NOPAT 利潤率路徑（出場年+1 … 終端），無偏估計
    k                 : 單位成長資本強度（每增加 1 元年營收所需的一次性資本支出）
    wacc              : rf + beta × ERP（或 total beta），不設下限常數
    回傳              : P/NOPAT 倍數（套在出場年 NOPAT／股上）＋隱含終端 RONIC
    """
    rev, pv = 1.0, 0.0
    for i in range(1, N + 1):
        g = g1 + (g_term - g1) * i / N
        m = nopat_margin_path[i - 1] - k * g        # FCF 利潤率 = NOPAT 率 − k·g
        rev *= (1 + g)
        pv += rev * m / ((1 + wacc) ** i)
    m_term = nopat_margin_path[-1] - k * g_term
    ronic_term = nopat_margin_path[-1] / k if k > 0 else float("inf")
    if ronic_term < wacc:
        g_term = 0.0
        m_term = nopat_margin_path[-1]
    tv = rev * (1 + g_term) * m_term / (wacc - g_term) / ((1 + wacc) ** N)
    return (pv + tv) / nopat_margin_path[0], ronic_term
```

#### 為什麼是成長連動形狀

```
capex/營收 = k·g + D&A/營收         （成長性 ＋ 重置性）
FCF 利潤率 = NOPAT 利潤率 − k·g      ← D&A 相消，逐年計算
隱含終端 RONIC = NOPAT 率 ÷ k        ← 必查
```

線性插值把 `m` 在**時間軸**上均勻推進，隱含「capex 強度隨時間線性下降」；但 capex 強度的驅動是**成長率**。當 `g` 已 fade 到 3%，線性插值仍給出很高的 capex／營收，等於主張「成長 3% 的公司還在花半數營收做成長 capex」。這個形狀誤差可以大到單獨改變結論，**且與 capex 絕對水準無關**——低資本強度的標的照樣中招，根因是 `g₁ − g_term` 的落差大小。

#### `k` 的四路徑校準（至少完成兩條並列出）

| 路徑 | 推導方式 | 資料層級 |
|---|---|---|
| ① 共識校準 | `k = (出場年 NOPAT 率 − 出場年共識 FCF 率) ÷ 出場年成長率`（客戶預付款顯著者本路徑失效，須註明） | l2 |
| ② 公司揭露校準 | 回本期 × 單位產能營收／利潤率 → 每單位產能 capex ÷ 單位產能年營收 | l1 |
| ③ 產業 sales-to-capital 倒數 | `k = 1 ÷ 產業 sales-to-invested-capital`（公開產業資料集，或自組同業組以「營收 ÷ 投入資本」計算） | l2，有外部母體 |
| ④ 承諾校準 | 未來 3 年採購／租賃／電力承諾總額（10-K Contractual Obligations 與附註）÷ 同期共識營收增量 | l1 |

- 至少兩條收斂（差距 <20%）方可直用，基準取**中值**；發散者仍取中值，並在敏感度分析以發散幅度設定不確定性寬度（**不是**「取保守端」——那是多重收費）。
- `k` 列入「本報告自設假設」清單，通常進入敏感度排序前段。
- **隱含終端 RONIC 檢查**：`RONIC = 終端 NOPAT 率 ÷ k`。與 WACC 差距 >5pp 者須說明其產業結構為何能永久維持超額報酬（價值驅動公式：`g` 對價值的影響符號由 `RONIC − WACC` 決定）；**RONIC < WACC 者 `g_term` 取 0%**——此時取 3% 反而是進取假設。

#### 參數約束＝紀律所在

逐項在報告中列出實際採值，並標明是否觸頂與母體：

| 參數 | 上限／規則 | 母體與來源 |
|---|---|---|
| **`g₁`** | ≤ min(出場年成長率, **40%**) | 紀律值。Chan-Karceski-Lakonishok（2003）顯示營收成長持續性略高於盈餘（5 年 6.3% vs 3.1%），但無 40% 的直接對照——**待回溯測試校準** |
| **`N`** | **預設 5 年**（上限 8 年須說明） | CKL 2003：盈餘成長連續 5 年高於中位數者僅 3%（≈純機率 3.1%），10 年 0.2%。8 年 fade 從 40% 起跌相對基準率並不保守 |
| **`g_term`** | ≤ **3%** 或估值幣別長期名目 GDP，取低者；**RONIC < WACC 者取 0%** | 一般 DCF 慣例 |
| **終端利潤率 `m_term`** | ≤ **同業組跨週期中位數（≥5 年、≥3 家具名同業）**，或由 `NOPAT_term − k·g_term` 在 RONIC 約束下推得。無可比同業時採分層預設 | ⚠️ **不得用「單一同業的單一期間現況」當永久上限**——那會讓本標的的每股價值被一家公司某一年的數字牽動 |
| **`m₁`** | 由 `NOPAT₁ − k·g₁` 推得並揭露 | 口徑鐵則 |
| **`k`** | 四路徑至少兩條並列出 | 見上表 |
| **`WACC`** | **`rf(10y 當期) + β × ERP`**；β 取同業組 unlevered β 再 relever；ERP 取當月隱含 ERP；投資人未分散者得用 **total β ＝ β ÷ 與市場相關係數**。**不設下限常數；不收個別風險** | Damodaran（2009）：年輕公司的存活風險走「估值 × 存活機率」兩步法，而非調折現率。客戶集中度、內控、上市年資、政策二元事件**移到情境機率** |

::: caveat
**★ 口徑鐵則（最容易犯、代價最大的一條）**：**fade 流量全程用「自由現金流利潤率」**，不得把起點寫成營業利益率、終點寫成 FCF 利潤率——對 capex 重的標的會**系統性高估**（實測可達 +58%）。

因成長期出場年 FCF 常為負，**分母改用出場年 NOPAT**，衍生倍數即為 **P/NOPAT**（不是 P/FCF、不是 P/E），須套在出場年 NOPAT／股上並明寫。

**副作用**：此形式下**出場年營業利益率會在分子分母相消、不影響價值**，它只決定倍數的表達方式 → **敏感度排序不得再把營業利益率列為關鍵假設**，通常由終端利潤率遞補。
:::

#### 配套規則

1. **參數觸頂揭露**：任一參數取到約束上限時，須明寫並說明為何該標的有資格取上限；**三情境的終端利潤率全部未觸頂亦應明寫**。
2. **終端利潤率對標同業組的三項可比性檢查**（對同業組**逐家**做，被排除者與理由逐一列出）：
   - **資本強度**：並列雙方 `capex／營收`。差距數十倍者，具名值只能作硬上限。
   - **商業模式**：對標者的 FCF 若由**高毛利軟體／廣告／授權**撐起，而本標的為純基建 → **不可移植**。
   - **資產壽命**：並列雙方核心資產折舊年限，**差 3 倍以上者不可移植**。
     ⚠️ 這條專門擋一類陷阱：長壽命建物型資產（20–40 年）的維護 capex 極低、FCF 利潤率全表最漂亮，資本強度檢查還會判它「輕」——但那是資產壽命的特權。短壽命機隊（4–6 年）的維護 capex ≈ 重置 capex ≈ 折舊。**只有第三項擋得住。**
   - 每家的 FCF 利潤率須取 **≥5 年中位數**並註明 capex 口徑與一手來源取得路徑。
3. **合理性檢查**：隱含市占（並列現任第一名份額與本公司現況份額倍數）；隱含終端 RONIC。
4. **三欄並陳**：本報告衍生倍數／現價隱含倍數／現價隱含 `g₁`；另附「線性形狀對照值」。

### C.5 稀釋必算

SBC 與可轉債在成長股是結構性稀釋來源。出場年股數須明列推估值與依據，並列入 Caveats。

- **稀釋與情境的相關方向須檢查**：里程碑型權證依營收或市值門檻歸屬時，**牛情境股數高於熊情境**。
- **深度價內可轉債**（且無 capped call）：股數計入計價股數、本金不再計為有息負債。
- **價外可轉債**（轉換價高於現價 20% 以上）：**計為債務、不計股數**；要呈現轉股情境則另列「全數轉股口徑」對照，**不得雙計**。
- 引用市值與 EV 時同時列出「行情站口徑」與「完全稀釋口徑」。

### C.6 控股折價不適用；歷史 band 常不適用

上市未滿 10 年、或期間經歷泡沫與崩跌者，依交叉驗證完成度聲明處理。

## 附：部位量化（選用）

**可投資性**依 SKILL.md 第二步判定。

- **錨的定義**：上檔錨 ＝ 牛情境紀律值；下檔錨 ＝ 熊情境紀律值。**賣方共識目標價、52 週高低點、IPO 低點不得進入任何計算**（前者系統性偏高：Bradshaw-Brown-Huang 2013；後者為價格錨：George & Hwang 2004）。
- **部位規模**：取下列兩者較小者——
  - **波動率倒數配置**：使每檔部位的年化波動貢獻相等（例：組合對單檔的 1σ 損失預算 ＝ 股票部位 2%）
  - **分數 Kelly（1/4）**：以三情境報酬率 `r_i = V_i / P − 1` 與機率 `p_i` 數值解 `max E[log(1 + f·r)]`，取 `f` 的 1/4

```python
def kelly_fraction(p, v, price, cap=1.0):
    import numpy as np
    r = np.array(v) / price - 1.0
    p = np.array(p)
    best, f_best = -1e9, 0.0
    for f in np.linspace(0, cap, 1001):
        if np.any(1 + f * r <= 0):
            break
        val = float(np.sum(p * np.log(1 + f * r)))
        if val > best:
            best, f_best = val, f
    return f_best          # 建議部位 = f_best / 4
```

- **下檔錨為負時（高槓桿標的的熊情境常見）**：**兩步都要做**——①floor 於 0（股權價值不得為負）並明寫；②**不得只做第①步**，單純 floor 會縮小分母、讓風險看起來變輕，與規則目的相反。必須同時把負值**轉譯為「補洞所需的稀釋比例」**（負股權金額 ÷ 當時預估股價 → 增發股數 → 對現有股東稀釋率）並列入 Recommendations。此時部位規模改以「**可承受全損金額**」界定。
- **出場條件（任一成立即觸發出場或出場覆核）**：①市價 > 牛情境紀律值；②核心論點門檻被證偽；③下一代產品週期 delta 由正轉負。**時間本身不觸發賣出**，只觸發覆核。
- **執行紀律**：每個建倉／減碼判定附**執行期限**（預設 5 個交易日）與**逾期預設動作**（執行一半，或書面寫明不執行理由並記錄）。
