# 估值紀律（內容層）

## 這個 skill 的定位

**這是一組預設值，不是教條。** 使用者若有自己的方法論文件（專案知識庫、CLAUDE.md、內部投資手冊），**那份是 source of truth**，本 skill 只補他沒寫到的部分。沒有的話，用本 skill 當骨架。

搭配 `/research-report-output` 使用：那邊管格式與交付，這邊管內容對不對。

> **本 skill 的核心主張只有一句**：保守性只能收一次費。多數估值錯誤不是某個參數抓錯，而是「營收打折 → 利潤率取下緣 → 倍數再降一級 → 折現率再加碼」四處各打一次折，相乘後的「基準情境」其實是 P10。**保守要放在情境機率與買入折價兩處，參數本身回到無偏最佳估計。**

---

## 第一步：估值路徑判別（兩層，寫報告前先答）

### 第一層——是否為單一事業體？（擇一成立即離開 SOTP）

1. 可獨立估值的事業分部 **< 2 個**；或
2. 分部**無獨立揭露之獲利率**（只揭露營收）；或
3. 主要產能位於**未併表合資**（權益法）。

> ⚠️ **判準 2 的邊界——兩種常見誤判都算單一事業體**：SOTP 需要的是分部**營業利益**。
> ① 公司揭露**產品線毛利率**但不揭露分部營業利益率、營業費用未分攤者；
> ② 公司以 **Adjusted EBITDA 為分部口徑**、**D&A 未分攤**、且 D&A 佔營收比重高者。
>
> **判斷口訣**：「這個分部揭露口徑，距離營業利益還差哪幾個科目？那幾個科目佔營收多少？」**差距 >25% 營收即視為未揭露**（25% 為經驗門檻，見 `references/calibration-and-governance.md`）。

### 第二層——週期股還是成長股？

| 判準 | 週期股 → 路徑 B | 成長股 → 路徑 C |
|---|---|---|
| 營收驅動 | 產能循環＋報價循環，有可辨識高低點 | 訂閱／續約黏著，無報價循環 |
| 獲利型態 | 峰谷差距數倍，常有虧損年 | 成長期利潤率受投入壓抑，非景氣所致 |
| 常態化的意義 | 跨週期平均**有**統計意義 | 跨週期平均**無**意義 |
| 分歧所在 | **分母**（正確的 EPS 是多少） | **分母＋出場年後的成長路徑** |

- 兩者皆不像（轉型中、剛上市、一次性事件主導）→ 走路徑 B，Caveats 寫明歸類理由。
- **混合型**（營收像成長股、損失像週期股，或需求端掛鉤外部 capex 週期）→ **仍走路徑 C**，週期變數以「利潤率情境」吸收。
- **歸類結果必須寫進估值節開頭。單一事業體不套控股折價。**

三條路徑的完整內容見 **`references/valuation-paths.md`**：

| 路徑 | 適用 | 核心 |
|---|---|---|
| **A｜SOTP** | 多分部且各有獨立獲利揭露 | 分部加總 ＋ 控股折價 **0–15%**（>15% 須具體理由） |
| **B｜週期股** | 單一事業、有報價循環 | 常態化獲利力雙法 × 週期位階倍數，並列跨週期 P/B |
| **C｜成長股** | 單一事業、無報價循環 | 遠期目標折現 ＋ **衍生**出場倍數（fade 模型推導，不得直接指定） ＋ 強制 Reverse DCF |

## 第二步：情境機率與期望值（所有路徑共用）

**這一步取代「R/R ≥ 2」「等待價」「動作錨」那一類單點門檻。**

1. **三情境各附主觀機率並寫理由。** 預設 熊／基準／牛 ＝ **25／50／25**；偏離預設者須逐項列出理由（哪一項財務品質警示、哪一項瓶頸、哪一項二元事件把機率移了多少）。
   **可分散的個別風險一律在此表達，不進折現率**——客戶集中度、內控狀態、上市年資、政策二元事件、許可審查，寫成「內控警示 → 熊情境機率 25% → 35%」，並在監控儀表板各佔一列作為機率回調的驗證條件。
2. **紀律值 ＝ 機率加權期望值**：`EV = p_bear × V_bear + p_base × V_base + p_bull × V_bull`。KPI 卡同時列三情境值與 EV。
3. **可投資性判定**：

   | 條件 | 評等 |
   |---|---|
   | `現價 ≤ EV × (1 − 安全邊際)` 且論點未破 | **可建首批** |
   | `EV × (1 − 安全邊際) < 現價 ≤ EV` | 觀察（可持有、不新增） |
   | `EV < 現價 ≤ 牛情境值` | 觀察（持有者覆核出場條件） |
   | `現價 > 牛情境值`，或牛情境值 ≤ 0 | **回避**；持有者觸發出場覆核 |

4. **安全邊際依波動率分級**（紀律值，須自行校準）：以 **90 日已實現波動率（年化）**分級——**<40%：20%；40–70%：30%；>70%：40%**。每次覆核重取。
5. **機率是自設假設**：列入 Caveats 的自設假設清單，敏感度須做「機率 ±10pp」，事後以 **Brier 分數** `(p − 結果)²` 覆盤校準。

> **為什麼是這個設計**：把「保守」放在每個參數，會讓紀律值與市價失去可比性，然後你需要第二套「動作錨」來救。把保守集中在機率（分布的形狀）與安全邊際（買價相對 EV 的折價）兩處，參數本身回到無偏，「紀律值 vs 市價」才重新是有意義的比較，pre-mortem 也才有一個可量化的出口。

## 第三步：敏感度分析的三條規則

1. **關鍵假設各做 ±10%／±20% 對 EV 的影響矩陣**，標出前兩名，回頭檢查其來源強度。走路徑 C 者關鍵假設為：營收錨、終端利潤率（或 NOPAT 路徑）、`g₁`、WACC、股數、`k`、情境機率（±10pp）。**⛔ 不含出場年營業利益率**（在 fade 模型中相消）。

2. **彈性排序失效的三種情形**——遇任一情形，**並列「機械式 ±20% 表」與「絕對擺幅表」（`|＋20% 值 − −20% 值|`），以後者為排序依據**；兩種排序不一致時，**兩個第一名都要跑下方三項處置**：
   - 純乘法模型（彈性恆為 ±1.00）
   - `|基準每股| < 現價 10%`（分母趨零，百分比彈性被放大而失效）
   - 假設上限被外部封死（如終端利潤率已觸頂，只能往下）

3. **排序第一名是「本報告自設」的假設時，三項強制處置**：
   - (a) 在 **TL;DR**（不是只在 Caveats）揭露「本估值的最大變數是 X，且 X 完全由本報告自設」**並寫出合理區間**
   - (b) **強制**做該假設 × 第二名的二維矩陣，並標出現價落點
   - (c) 加碼訊號至少一項是該假設的**直接驗證條件**，且對應監控儀表板一列

   > 第一名若為 **WACC**，驗證條件是無風險利率與 ERP 的當期值（總體前提），不是個別風險因子；第一名若為**情境機率**，驗證條件是機率移動理由各佔一列。

4. **倍數典範揭露**：結論與市價的差距若主要來自倍數，須以同分母、同基年並陳——本報告衍生倍數／**現價隱含倍數**／**現價隱含 `g₁`**。第三欄是業務語言，比倍數更能傳達分歧在哪。

## 第四步：交叉驗證

估值結論須與下列方法交叉比對，重大分歧時說明原因：

1. **Reverse DCF**——回推現價隱含的成長與利潤率假設。
2. **歷史估值 band**——近 10 年 P/B 與 P/E 區間位階。上市未滿 10 年或期間經歷泡沫崩跌者，依完成度聲明處理。
3. **資產重估**——土地與轉投資市值重估；清算價值錨若無實務意義須明寫「僅作理論下限」。
4. **同業倍數比較**——同一基年、同一口徑、每列標查價日；註明每家是輕資產或重資產。

**規則三條：**

- **完成度聲明**：任一方法不適用時允許放棄，但**必須在 Caveats 明列理由，並聲明「交叉驗證實際完成 N 方」**。
- ⚠️ **走路徑 C 者，Reverse DCF 不計為獨立一方**——它與主軸共用同一 fade 引擎，功能是**分歧定位**（市場的參數組合是什麼、我差在哪一格），不是驗證。第三方驗證另尋同業倍數、歷史 band、資產法。
- **驗證與主軸相反時必須明示**（同向時亦須明寫）。相反時**先問兩者是否在問同一時間尺度的問題**——同業表看下一年、fade 模型看出場年後六年，時間尺度差異須明寫，不得一律歸為「方法論選擇」。背離 >40% 時，**先檢查情境機率與基準參數是否仍殘留多層保守**，其次才是 fade 參數誤設。

## 來源紀律（估值假設專用）

- 所有關鍵數據一定要**一手權威來源**：公司財報、法說會簡報／逐字稿、官方文件庫（MOPS／SEC EDGAR）、具名的產業研究。
- **絕不可**用一般投資人部落格內文當來源；參考到須回溯改引原始一手來源。
- **對標同業須具名**：以同業作為參數上限者，須具名**同業組（≥3 家）**、列出各家 ≥5 年中位數、查詢日、口徑與一手來源取得路徑，並逐家做可比性檢查；被排除者與理由亦須列出。寫「參考同業水準」而不具名，視同未查證。
- **常數的母體聲明**：框架內任何常數（倍數上限、折讓、門檻）被使用時，須能回答「這是從哪類公司、哪段期間校準的」；母體不同於本標的者，須在 Caveats 註明外推風險。

## 交付前：跑內容層檢查清單

**12 項，任一未過不得發布**——見 `references/prepublish-checklist.md`。

最容易漏的四項：
- 走路徑 C 者的**口徑一致性**（fade 流量全程 FCF 口徑、分母為出場年 NOPAT、倍數明寫 P/NOPAT）
- **基準情境參數殘留「取下緣」「取保守端」字樣**（保守多重收費）
- **事件已發生但結果未取得**亦須標基線版
- **敏感度排序第一名為自設假設**時的三項強制處置
