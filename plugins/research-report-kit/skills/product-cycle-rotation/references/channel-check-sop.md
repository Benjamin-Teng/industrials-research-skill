# Channel Check SOP

---

## 0. 合規紅線（必讀，優先於一切報酬考量）

- **法律邊界**：各市場的內線交易與重大未公開資訊（MNPI）規範。**不得索取、收受、使用「未公開之重大消息」。**
- **安全做法＝拼圖法（mosaic theory）**：蒐集多個「個別不重大、且公開或半公開」的碎片，靠自己的分析拼出全貌。價值在**拼圖的能力**，不在拿到別人沒有的那一塊。
- **問句紅綠燈**：
  - ✅ 產業層級（「這個世代的散熱方案大概往哪個方向走？」）
  - ✅ 趨勢層級（「認證週期最近有變長嗎？」）
  - ❌ 公司特定 ＋ 未公開 ＋ 重大（「A 公司下季訂單多少？」）
- **紀錄原則**：channel check log **不記錄任何可識別個人的資訊，不記錄具體機密數字**。記的是「口徑」與「方向」，不是「數字」。

> 本節為研究紀律摘要，非法律意見。遇灰色地帶，保守處理或諮詢專業。

## 1. 資訊來源分層

| 層級 | 來源 | 領先性 | 成本 | 可信度處理 |
|---|---|---|---|---|
| **L1 展會實地** | 產業展會與技術研討：攤位工程師交流、技術演講、展品規格表 | 6–12 個月 | 門票＋時間 | 一手觀察，最高等級 |
| **L2 供應鏈媒體** | 供應鏈研究機構、產業日報的供應鏈版 | 3–9 個月 | 訂閱費 | 具名報導 ＞ 未具名；後者須等第二**消息源** |
| **L3 法說會三角驗證** | 上游講產能、中游講訂單、下游講需求 | 0–6 個月（**對第三方是領先資訊**） | 免費 | 一手來源 |
| **L4 人脈網絡** | 前同事、供應鏈從業者、經銷商、獵頭 | 6–12 個月 | 關係維護 | 必須雙源交叉；**嚴守第 0 節** |
| **L5 另類數據** | 徵才量、進出口統計、外銷訂單、資本支出公告、環評／建照申請、地方許可議程、13F 機構持股集中度 | 3–12 個月 | 免費–低 | 客觀但需解讀；當佐證 |

**L3 是最被低估的一層。** 上游原廠講的產能數字，對下游模組廠的投資人是領先資訊——它已經公開，但沒人把三邊的口徑擺在一起看。

## 2. 執行 SOP（六步循環）

### Step 1 — 建圖

為追蹤中的每個 product cycle 建立供應鏈地圖（BOM tree）。**每季全面更新。**

### Step 2 — 出題

每月定義 3–5 個「本月必須驗證的問題」。

**好問題的三條件**：**可證偽**、**有時效**、**答案會改變部位**。三者缺一就不是好問題——「這個產業前景如何」三條都不符合。

### Step 3 — 採證

每個問題至少從**兩個獨立來源**取證。

⚠️ **獨立性 ＝ 推定原始消息源不同。** 不同層級或不同陣營只是必要條件；兩家媒體引用同一份券商通路調查、或同一場展會的同一位工程師，**只算一源**。

**單一來源 ＝ 只能記錄、不能行動。**

### Step 4 — 記錄

寫入 channel check log（見第 3 節）。

### Step 5 — 比對

與市場共識對照，三種結果：

| 結果 | 處理 |
|---|---|
| 共識已反映 | 無交易價值，記錄後結案 |
| 領先共識 | 可行動 |
| 與共識矛盾 | **提高採證等級後**再行動 |

⚠️ **對稱條款**：削弱既有持倉論點的證據，採證等級要求與支持證據**相同**，且一律觸發覆核。**不得因「只是單源」而擱置**——這是確認偏誤最常見的入口。

### Step 6 — 行動

依輪動倉規則執行加減碼，並把「後續驗證點」寫回監控清單。

**節奏**：每月一輪輕量；每季一輪深度（含 Step 1 全面更新 ＋ Q5 重掃）。

## 3. Channel Check Log 格式

| 欄位 | 說明 |
|---|---|
| 日期 | — |
| 問題編號 | 對應 Step 2 |
| 來源層級 | L1–L5 |
| 來源描述 | **類型化描述，不記可識別個資** |
| **推定原始消息源** | 這條資訊最可能從哪裡來（某券商通路調查／某展會／某法說會／某供應商業務）——**用於判定獨立性** |
| 內容摘要 | 只記事實與口徑 |
| 可信度 | A（一手觀察／具名揭露）／B（未具名但**不同消息源**雙源一致）／C（單源未驗證） |
| 與前次差異 | 進度提前／延後；口徑轉強／轉弱 |
| 對論點影響 | 支持／中性／削弱**哪一個**持倉論點 |
| 後續動作 | 需再驗證／觸發加減碼／無 |

**升級規則**：只有 A、B 級可作為行動依據；C 級累積兩個**不同消息源**後自動升級為 B。

**「與前次差異」欄是這張表的價值所在**——單次觀察沒有訊息量，方向的變化才有。

---

## 4. 與估值框架的調和

- **輪動倉**：雙源驗證（B 級）以上的 channel check 可直接作為行動依據。
- **重倉**：仍須等一手來源確認、且深度估值框架跑完、且折價 ≥ 安全邊際，才能升級部位。
- **一句話原則**：**channel check 決定 timing 與 watchlist；一手來源與估值紀律決定 sizing。**

若日後覆盤顯示 B 級證據的行動勝率不足，應收緊這一節的門檻。

## 5. 工具箱

### 5.1 免費工具

| 工具 | 用途 |
|---|---|
| 官方文件庫 ＋ 交易所 OpenAPI | 營運數據、財報、重訊、法人籌碼 |
| SEC EDGAR（10-K／10-Q／8-K／13F） | 美股正式揭露；13F 用於擁擠度 |
| 法說會影音專區、公司 IR 網站 | L3 三角驗證的原料 |
| 產業展會議程與 keynote 重播 | L1 的遠端替代 |
| 徵才平台（本地 ＋ LinkedIn） | L5 擴產訊號 |
| 海關進出口統計、外銷訂單 | L5 總量佐證 |
| 公開總體資料集（FRED、ERP／sales-to-capital 資料集） | 折現率與資本強度的輸入 |
| 技術媒體（拆機與規格庫） | Q1 BOM 對照的規格原料 |

### 5.2 付費工具

| 工具 | 具體價值 | 何時值得買 |
|---|---|---|
| 供應鏈研究機構 | 訂單／擴產最即時的具名報導 | 認真做供應鏈輪動即必備 |
| 零組件報價資料庫 | 記憶體與零組件報價 | 交易報價驅動的族群時 |
| 獨立技術研究 | 硬體架構深度分析，Q5 的關鍵輸入 | 追世代交替時 |
| 券商研究報告 | 共識基線與產業 primer | 以免費管道補齊樣本即可 |
| 專家訪談平台 | 機構級 channel check 逐字稿 | 成本高，多數個人投資者不划算 |

### 5.3 值得自建的工具（依優先序）

**P0**：①營運數據監控器；②新聞關鍵字監控＋每日摘要；③催化劑日曆。
**P1**：④法說會 pipeline；⑤Channel check log 系統（含「推定原始消息源」欄與獨立性自動判定）；⑥報價儀表板。
**P2**：⑦Design win 追蹤資料庫；⑧法人籌碼與借券監控（含機構持股集中度）；⑨**預測記分資料庫**（標題推演、情境機率、pre-mortem 三類預測的 Brier 分數與校準曲線）；⑩組合曝險計算器（對產業指數的組合 beta、有效押注數）。

**建置原則**：每個工具先做「能跑的最小版」；**全部工具共用一份觀察名單設定檔**。
